Core modules

Entry pointWhat it provides
qjs:stdQuickJS std module: stdio, files, exit, errno, eval helpers.
qjs:osQuickJS os module: fd I/O, timers, environment, cwd, exec helpers, Amiga additions.

import * as os from 'qjs:os';

std.puts('hello\n');
print(os.platform);

Native embedding API

#include <proto/quickjs.h>

struct Library *QuickJSBase;
QuickJSBase = OpenLibrary("quickjs.library", 0);

JSRuntime *rt = QJS_NewRuntime();
JSContext *ctx = QJS_NewContext(rt);

JSValue result;
QJS_Eval(&result, ctx, "2 + 2", 5, "<input>", 0);

Native callers use the QJS_ API because Amiga library calling conventions differ from upstream QuickJS C calls. JSValue returns use output pointers, value parameters are often pointers, and doubles cross as pointers.

API surface is intentionally practical, not a full Node clone.
