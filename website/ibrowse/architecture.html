AmigaOS library rules

  • All JavaScript-facing functionality belongs in quickjs.library, not in a special CLI binary.
  • The shared library avoids normal C startup assumptions. It calls dos.library and exec.library directly where needed.
  • Functions exposed through the library use QJS_ names to make ABI differences explicit.
  • Values that cannot cross the 68k library jump table directly, such as JSValue, use output pointers.
  • Each CPU/FPU variant carries a self-identifying $VER: string.

Runtime flow

qjs
  opens LIBS:quickjs.library
  creates JSRuntime and JSContext
  installs std/os/bjson and extended APIs
  evaluates startup file, script, -e input, or REPL
  drains jobs and timers through library helpers

Native integration

The port replaces missing POSIX assumptions with Amiga implementations: file I/O through dos.library, time through DateStamp/timer.device, console raw mode through Amiga console handlers, networking through bsdsocket.library, TLS through AmiSSL where available, and GUI through Intuition/Reaction.

Use api.html for developer-facing surfaces.
