JavaScript for classic AmigaOS

nea-quickjs ports QuickJS-ng to 68020+ Amigas and packages it the Amiga way: as quickjs.library. The command line qjs program is only one client. Any Amiga application can open the library and embed a JavaScript runtime.

The goal is practical: make this the default JavaScript platform for old Amigas, with useful Node-style APIs, AmigaOS-native file and network bridges, and real GUI scripting through Intuition and Reaction.

Platform features

  • QuickJS-ng language runtime with REPL, module imports, std, os, and bjson support.
  • Node-inspired globals: Buffer, EventEmitter, process, fs, path, util, URL, timers, streams, querystring, readline, and child process helpers.
  • Web-style APIs: fetch(), AbortController, TextEncoder, TextDecoder, structuredClone, and crypto.subtle.digest.
  • Amiga-native bridges for dos.library, exec.library, bsdsocket.library, AmiSSL, timer.device, Intuition, Graphics, ASL, Diskfont, GadTools, and Reaction.
  • Amiga-friendly behavior: S:QJS-Config.txt, S:QJS-Startup.js, Amiga path handling, console CSI translation, soft-float builds, and stack checks.

Reaction and BOOPSI from JavaScript

The amiga.boopsi layer wraps Reaction classes as JavaScript objects. Scripts can build windows, layouts, buttons, labels, sliders, list browsers, palettes, requesters, file pickers, tabs, gauges, and other OS3.x gadgets without hand-building tag lists or dispatching BOOPSI methods manually.

  })
});

Build and ship

The build produces library variants such as quickjs.020soft.library, quickjs.020fpu.library, quickjs.040soft.library, quickjs.040fpu.library, quickjs.060soft.library, and quickjs.060fpu.library. 

make lib
make cli
stack 65536
execute tests/run-tests.script

Copy the appropriate library to LIBS:quickjs.library and put qjs somewhere on the command path. Applications can also link against the pragma/proto headers and call the QJS_* API.

Built for old browsers first: no frames, no required JavaScript, no CSS grid, no web fonts, and no modern layout dependencies.
