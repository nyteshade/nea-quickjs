Why it exists

Raw Reaction code requires opening class libraries, finding class pointers, building tag lists, creating objects, dispatching BOOPSI methods, and translating IDCMP messages. The amiga.boopsi layer keeps the Amiga model visible but wraps the ceremony in JavaScript classes.

Event model

Window.events() yields rich events. It decodes Reaction's window-class input handling, maps gadget IDs back to JavaScript objects, and upgrades generic events to class-specific kinds such as BUTTON_CLICK, SLIDER_CHANGE, LIST_SELECT, and FILE_SELECTED.

for (let evt of win.events()) {
  if (evt.kind === EventKind.CLOSE_WINDOW) break;
  if (evt.kind === EventKind.BUTTON_CLICK) {
    print('button ' + evt.sourceId);
  }
}

Tag lists still matter

The wrapper accepts JavaScript object properties, but the implementation remains a BOOPSI tag-list system underneath. Advanced code can still drop to amiga.makeTags(), amiga.withTags(), amiga.openLibrary(), and amiga.call().
