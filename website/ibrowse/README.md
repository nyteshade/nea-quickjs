# IBrowse Site

This variant targets old Amiga browsers such as IBrowse 3.

- HTML 4.01 Transitional
- no required JavaScript
- no flexbox, grid, custom properties, web fonts, or SVG dependency
- fixed-width table-friendly layout
- ISO-8859-1 declaration with ASCII-only page text

Open `index.html` directly in IBrowse or serve it as static content.
