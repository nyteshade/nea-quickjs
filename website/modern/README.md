# Modern Site

React + Radix UI version of the nea-quickjs project site. It intentionally uses
plain JavaScript (`.jsx`), not TypeScript.

## Run

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Stack

- Vite
- React
- Radix UI primitives: Accordion, Dialog, Progress, Switch, Tabs, Tooltip
- lucide-react icons

The factual project copy is centralized in `src/content.js`.
